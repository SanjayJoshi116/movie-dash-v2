MovieDash v2 — Feature List

DASHBOARD (/)
- Landing summary: stat cards (total movies, average rating, average runtime, total box office)
- Highlight cards: top rated, most popular, newest release
- Trends & Breakdown: 10-year release trend, top-6 genre breakdown, rating distribution, recent releases list (click to open detail drawer)
- CTA cards linking to Movies and Stats
- Standardized section layout (title + spacing) via a shared DashboardSection wrapper

MOVIES (/movies)
- Table or grid view via Segmented toggle (grid = card layout, table = dense sortable list)
- Always-visible search box (name, director, actor, genre, production company)
- Filters button opens a right-side drawer with grouped Category filters (language, genre, director) and Range filters (year, vote average, runtime, box-office revenue); dot indicator when a filter is active
- Removable filter chips summarizing active filters, one-click "Clear all" shown directly on the page
- Filter state persisted across page refreshes (localStorage)
- Sortable columns (table view)
- Pagination (5 / 10 / 20 / 50 per page, table view)
- Row/card click opens detail drawer (full movie info, vote count, popularity score); rows/cards keyboard-activatable (Enter/Space) with aria-labels
- Export filtered results to CSV
- Sidebar auto-collapses below 768px viewport width (Ant Design breakpoint hook), manual toggle still works; sidebar sticky-positioned
- Below the sm breakpoint: sidebar replaced by fixed bottom nav bar (Dashboard/Movies/Stats), grid view default, detail/filters drawers go full-width, table columns hide progressively, pagination switches to simple mode
- Release dates rendered as DD-MM-YYYY (table + detail drawer)

STATISTICS (6 tabs)
- Overview: animated stat cards (total movies, avg/longest/shortest runtime, total watch time in minutes/hours/days/years), movies by language, movies per year
- People: top 15 actors, top 15 directors, movies by production company
- Ratings: vote distribution, avg vote by language (radar), avg vote by genre
- Runtime & Geography: movies by country & genre (polar area), avg vote by runtime bucket, top 50 longest films
- Box Office: top 20 highest-grossing films, top 20 highest-budget films, avg revenue by genre
- Explore: genre distribution, year x genre heatmap, Top 10 Explorer (highest rated / longest / most recent / oldest / most popular)

THEME
- Light / dark toggle, preference persisted to localStorage
- Glassmorphism design system via CSS custom properties

BACKEND / DATA
- Express API under /api (gzip-compressed, cached) serving movie data from a local CSV
- /api prefix keeps Vite dev proxy from colliding with client-side routes like /movies
- CSV template + TMDB API sourcing guide included
- movie-search.py: Tkinter GUI to search TMDB (by movie or actor, language filter, pagination) and append picked results to src/movies.csv; TMDB_API_KEY read from .env (never hardcoded)

SECURITY
- helmet() security headers on all responses
- Rate limiting on /api/* (300 req/min per client via express-rate-limit)
- CORS allowlist restricted to CLIENT_ORIGIN env var (default http://localhost:3000), not an open cors()
- Movie ID route param length-validated before lookup (400 on invalid)
- Catch-all error-handling middleware returns generic 500 JSON, logs server-side, no stack trace leak

QUALITY
- ESLint (typescript-eslint, react-hooks, unused-imports)
- 47 Playwright E2E tests across 7 suites
- GitHub Actions CI: npm audit (critical) + lint + build + e2e on push/PR to main
- MIT licensed
