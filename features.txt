MovieDash v2 — Feature List

DASHBOARD (/)
- Landing summary: stat cards (total movies — hero-styled with icon, average rating, average runtime, total box office), each with an icon
- Highlight cards: top rated, most popular, newest release — with poster thumbnail; click or Enter/Space opens that movie's detail drawer
- Total Box Office stat card clickable, jumps to Stats page's Box Office tab
- Trends & Breakdown: 10-year release trend (continuous span, empty years shown as 0), top-6 genre breakdown, rating distribution (each clickable — jumps to Movies pre-filtered by that year/genre/vote range), recent releases list with poster thumbnails (click or Enter/Space to open detail drawer)
- Skeleton placeholder layout while data loads (instead of a bare spinner)
- Empty state (0 movies): Empty component + "Go to Movies" CTA instead of zeroed-out stats/charts
- CTA cards linking to Movies and Stats
- Standardized section layout (title + spacing) via a shared DashboardSection wrapper

MOVIES (/movies)
- Table or grid view via Segmented toggle (grid = card layout with poster thumbnail, up to 6 cards/row on wide screens, taller cover to show more of the poster, own sort dropdown for name/year/rating/runtime; table = dense sortable list)
- Poster shown in grid cards and the detail drawer when a movie has a Poster URL in the CSV; falls back to a placeholder otherwise
- Always-visible search box (name, director, actor, genre, production company/country, release year, language name)
- Filters button opens a right-side drawer with grouped Category filters (language, genre, director) and Range filters (year, vote average, runtime, box-office revenue — an active revenue/vote range excludes movies with unknown revenue / unrated); dot indicator when a filter is active
- Removable filter chips summarizing active filters, one-click "Clear all" shown directly on the page
- Filter state persisted for the tab/session (sessionStorage) — survives nav within the tab, resets on new tab/restart; restored filters are validated and clamped to the current data
- Adding/deleting a movie refreshes the list in the background — open dialogs, sort, page and search are kept; changing filters returns to page 1
- Range sliders apply on release (no refilter per drag tick)
- Sortable columns (table view)
- Pagination (5 / 10 / 20 / 50 per page, table view)
- Row/card click opens detail drawer (full movie info, vote count, popularity score); keyboard: the movie name in each table row is a button (Enter/Space), grid cards are focusable — table rows keep proper table semantics for screen readers
- Export filtered results to CSV — in the order the table/grid currently shows them, with every catalogue column, formula-like cells guarded
- "Add Movie" button opens a modal to search TMDB (by movie name and/or actor, optional release-year narrowing) and import a result straight into the running catalogue — no need to leave the browser or use movie-search.py
- Detail drawer has a Delete button (confirm required) to remove a movie from the catalogue
- Sidebar auto-collapses below 768px viewport width (Ant Design breakpoint hook), manual toggle still works; sidebar sticky-positioned
- Below the sm breakpoint: sidebar replaced by fixed bottom nav bar (Dashboard/Movies/Stats), grid view default, detail/filters drawers go full-width, table columns hide progressively, pagination switches to simple mode
- Release dates rendered as DD-MM-YYYY (table + detail drawer)

STATISTICS (6 tabs)
- Global Release Year Range slider scopes all 6 tabs to a chosen year span at once, with a Reset button once narrowed
- Active tab synced to a ?tab= URL query param from the first render (including after a Dashboard link) — survives reload, shareable/bookmarkable; unknown ?tab= values fall back to Overview
- Every chart card has a PNG-download button (exported on an opaque background matching the theme)
- Most charts are clickable — clicking a bar/slice jumps to Movies pre-filtered by that value (genre, language, director, vote range, runtime bucket, decade); the list always matches what the chart counted (shared bucket bounds, so boundary values never land in two buckets), drill-downs carry the global Release Year Range, and "Other"/"Unknown" slices aren't clickable (no pointer cursor)
- Category charts show at most 7 named slices + "Other", each in a distinct palette colour; money axes read $0 at zero and -$X for losses
- Overview: animated stat cards (total movies, avg/longest/shortest runtime, total watch time in minutes/hours/days/years), movies by language, movies per year
- People: top 15 actors, top 15 directors, movies by production company, highest rated directors, highest rated actors & actresses (2+ films)
- Ratings: vote distribution, avg vote by language (radar), avg vote by year (trend), avg vote by genre, vote count vs vote average (scatter, outlier check)
- Runtime & Geography: movies by country & genre (polar area), avg vote by runtime bucket, avg runtime by decade, top 50 longest films
- Box Office: top 20 highest-grossing films, top 20 highest-budget films, top 20 most profitable films (revenue − budget), top 20 by ROI (revenue / budget), avg revenue by genre
- Explore: genre distribution, year x genre heatmap, Top 10 Explorer (highest rated — min. 50 votes / longest / most recent / oldest / most popular)

THEME
- Light / dark toggle, preference persisted to localStorage (first visit follows the OS preference; works even when storage is blocked)
- Refined glassmorphism design system — shared surface/spacing/typography tokens (CSS custom properties + chartTheme.ts) applied consistently to sidebar, top bar, bottom nav, and every page; calmer border/shadow, muted 8-color chart palette

BACKEND / DATA
- Express API under /api (gzip-compressed; /api/movies revalidated via no-cache + ETag, so adds/deletes show up immediately) serving movie data from a local CSV
- Catalogue writes are serialized through one op queue (no lost/duplicated rows under concurrent add/delete); the server re-reads the CSV when another tool changes it on disk, so rows added by movie-search.py / backfill_posters.py while it runs are preserved
- Duplicate imports (double-click, two tabs) rejected with 409 and stored once
- Tolerates hand-edited/Excel-saved CSVs: UTF-8 BOM, missing trailing newline; refuses to append to a file with no readable header
- GET /api/tmdb/search (name/actor/year) and POST /api/tmdb/import — server-side TMDB proxy powering the in-app Add Movie modal; TMDB_API_KEY read from .env server-side (process.loadEnvFile), never sent to the client; import calls retry network errors and 429/5xx (3 attempts, backoff) via axios, not the native fetch (undici), which was found to get TLS-reset by AV/proxy HTTPS inspection on some Windows setups
- DELETE /api/movies/:id — removes a movie and regenerates src/movies.csv (write-to-uniquely-named-temp-then-rename, so a crash mid-write can't truncate the file; on a failed write both file and served catalogue stay unchanged)
- /api prefix keeps Vite dev proxy from colliding with client-side routes like /movies
- CSV path resolved via process.cwd() (not __dirname), so the compiled production server (server/dist/server/server.js) reads the correct src/movies.csv, same as dev
- CSV template + TMDB API sourcing guide included
- One canonical CSV value format shared by the in-app import, movie-search.py and the README guide: multi-value columns (genres, cast, production companies/countries) list every full name comma-joined; missing values left empty (legacy "N/A" placeholders read as empty)
- Country and production-company charts split comma-joined values, so co-productions count toward each country
- movie-search.py: Tkinter GUI to search TMDB (by movie or actor, language filter, pagination) and append picked results (incl. poster URL) to src/movies.csv; TMDB_API_KEY read from .env (never hardcoded), always sent via requests' params= (not URL-interpolated); appends stay column-aligned with an existing CSV's own header, even one predating the Poster URL column. Still available for bulk/offline use alongside the in-app Add Movie modal.
- backfill_posters.py: one-off script to fill Poster URL for existing CSV rows via TMDB lookup by Movie ID; checkpointed every 100 rows (each checkpoint written to a temp file and atomically swapped in, so interrupting it can't truncate the CSV), reports a specific skip reason per row

SECURITY
- helmet() security headers on all responses
- Rate limiting on /api/* (300 req/min per client via express-rate-limit)
- CORS allowlist restricted to CLIENT_ORIGIN env var (default http://localhost:3000), not an open cors()
- Movie ID route param length-validated before lookup (400 on invalid)
- Catch-all error-handling middleware returns generic 500 JSON, logs server-side, no stack trace leak; body-parse client errors keep their real status (400 malformed JSON, 413 oversized body)
- TMDB_API_KEY only ever read/used server-side (GET /api/tmdb/search, POST /api/tmdb/import); never sent to the client
- CSV rows appended via TMDB import are sanitized against formula injection (=, +, -, @ prefixes get a leading '), same guard as movie-search.py; the guard is stripped on read so titles like "+1" display correctly and are never double-escaped
- Delete Movie requires an explicit confirm (Popconfirm) before removing a row
- movie-search.py never echoes raw request exceptions (could include URL/key) back to the user in error dialogs

QUALITY
- ESLint (typescript-eslint, react-hooks, unused-imports)
- 59 Playwright E2E tests across 10 suites
- 44 server API tests (node:test via tsx) against temp CSVs with a stubbed TMDB client — never touch src/movies.csv or the network
- GitHub Actions CI: npm audit (high, 0 vulnerabilities) + lint + server type-check + build + server tests + e2e on push/PR to main
- Requires Node.js 22.22+ (react-router v8 requirement)
